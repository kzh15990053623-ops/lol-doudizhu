# 游戏体验与品质优化验收

日期：2026-09-20。范围：当前本地 React / TypeScript 项目。已完成已确认方案的规则、AI、操作反馈、布局、续局与成长功能，并运行本地验收。

## 玩家能感受到的变化

- **更可靠的规则**：补全连续三张、飞机带单 / 对、四带二单 / 两对；修复首出禁炸弹、护盾阵营、盖伦插队与回合恢复、状态被无关动作消耗等问题。
- **更合理的技能**：提莫降低敌方下一手普通牌的比较强度，过牌和炸弹不消耗；锤石从已结算弃牌中选一张 3–10 与手牌等量交换；凯特琳与锤石城邦公开牌面，而非仅显示无法利用的提示。定向技能只允许选择敌方。
- **更有配合的 AI**：增加休闲 / 标准两档；标准策略考虑剩余组合、拆炸弹代价、敌方收尾风险、农民让牌与技能时机。决策入口屏蔽未揭示的对手手牌，重复侦查信息按牌去重。
- **更清楚的操作**：技能先选目标或交换牌、预览再确认；取消不消耗。提示说明推荐原因；无法压制时明确建议过牌。对手行动期间可预选，轮到自己时保留选择。
- **更完整的反馈**：同次操作的技能、城邦、胜负事件顺序播报，完成后再显示结算；声音按实际发动者播放，结合短音效与现有六名英雄语音。已知牌、公开弃牌、状态及完整记录可随时查阅。
- **更适合横屏**：调整桌面与手机布局，手牌横向浏览，667 / 812 宽度下相邻手牌露出的可点击间距达到 44px。选英雄页说明与按钮不再重叠。键盘可滚动阅读弹层。
- **更完整的单机循环**：自动续局、版本检查、主动放弃确认、按阵营积分、最近 20 局战绩、累计英雄胜场与首胜徽章。同英雄重开使用新牌局种子；固定练习不计战绩。

规则保持简化抢地主与加法倍率。飞机主体不能包含 2 / 王，翅膀不复用主体点数；带单不允许同时使用双王，带对使用不同点数的对子。双方农民共同胜负：地主 `±20 × 倍率`、每名农民 `±10 × 倍率`，总积分为零。

## AI 对照结果

方法：600 个相同初始牌局，各运行两次。只有玩家 0 从参考策略切换为标准策略；其余两个座位保持参考策略。参考策略在当前相同规则下复现“36% 概率发动技能、否则使用首条合法提示”，锤石交换参数按新规则适配。每局最多 300 次行动，遇到非法动作或未结束即失败。

| 玩家 0 的阵营 | 牌局数 | 参考策略胜场 | 标准策略胜场 |
| --- | ---: | ---: | ---: |
| 地主 | 200 | 83（41.5%） | 119（59.5%） |
| 农民 | 400 | 201（50.3%） | 227（56.8%） |
| 合计 | 600 | 284（47.3%） | 346（57.7%） |

标准策略净增加 62 个胜场，即 **10.3 个百分点**；110 局从败变胜，48 局从胜变败。本机决策耗时 p50 为 0.133 ms，p95 为 0.716 ms，最大值为 5.973 ms。耗时受机器和负载影响；此对照支持策略提升，不代表真人胜率或十二名英雄已达到竞技平衡。

复现：`node scripts/benchmark-ai.mjs 600`。原始结果：`.audit-output/quality-ai-benchmark.json`。
