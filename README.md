# 符文之地斗地主

一个纯静态、单机的三人斗地主游戏。玩家与两名 AI 使用英雄主动技能；地主英雄会激活对应城邦规则。支持本机续局、练习引导、阵营积分和英雄首胜记录。

前端基于 React 19、TypeScript、Vite 8 和 CSS Modules。牌型、技能、AI、回合与结算位于纯领域层，不访问 DOM、音频、计时器或本地存储。

## 环境与启动

需要 Node.js `>=22.12`。

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址（Vite 默认是 `http://localhost:5173/`）。也可以双击 `启动游戏预览.bat`，它会使用 `http://127.0.0.1:5175/`。

地址栏可附加 `?seed=<值>` 固定初始牌局的种子。当前开发与生产入口的优先级不同：

- 开发服务器：显式指定 `?seed=` 会跳过存档恢复，按种子重新初始化，并替换原有续局进度；不指定时正常恢复存档。
- 生产构建：优先恢复有效存档，包括抢地主、进行中和已结束的结算状态；仅在没有有效存档时使用 `?seed=`。若要指定种子重新开始，先从游戏内返回英雄选择以清除牌局进度，再打开带 seed 的地址。仅结束对局不会清除存档。

## 操作

- 点击卡牌选牌；手牌内使用方向键移动，`Home` / `End` 跳到首尾，`Enter` / `Space` 切换选中。
- `P` 出牌、`H` 提示、`X` 不要、`S` 打开技能确认。需要目标或换牌的技能会先让你选择，取消不会消耗技能。
- `Esc` 关闭当前弹层，或在牌桌上清空选牌。
- 中央牌区显示目标牌、比较点数、底牌和最近两次对手行动。“记录”中可查看完整行动、公开弃牌、已知手牌与状态持续条件；手机通过菜单进入。
- 等待对方行动时可以预选手牌；轮到自己后仍然保留。提示按剩余牌型与局势排序，并说明推荐原因。
- 手机横屏可水平浏览手牌，实际露出的相邻点击间距不少于 44px。竖屏、切到后台或打开弹层会暂停 AI。
- 设置中可选休闲 / 标准难度、普通 / 快速节奏，调整或关闭声音。声音在首次操作后启用。

## 规则、续局与成长

- 常规牌型覆盖单牌、对子、三张、三带一 / 对、顺子、连对、连续三张、飞机带单 / 对、四带二单 / 两对、炸弹、火箭。顺子和飞机主体不含 2 / 王；飞机翅膀不复用主体点数，带单不允许同时带双王，带对要求不同点数。
- 保留简化抢地主和加法倍率。结算按阵营：地主胜负为 `±20 × 倍率`，每名农民为 `±10 × 倍率`；农民队友获胜也算自己的胜利。
- 进行中的牌局每次行动后自动保存。正常入口刷新会续局；放弃当前牌局前需要确认。设置兼容原有版本，损坏或规则版本不匹配的牌局会给出解释。
- 最近 20 局、累计英雄胜场和 12 枚英雄首胜徽章保存在当前浏览器。再来一局沿用自己的英雄并重新发牌。
- “两分钟上手练习”使用固定金克丝牌局，演示选牌、提示、技能确认与城邦联动，不写入战绩。

## 质量检查

```powershell
npm.cmd run check
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run test:ui
npm.cmd run build
npm.cmd run test:budget
npm.cmd run test:e2e
npm.cmd run test:a11y
node scripts/benchmark-ai.mjs 600
```

- Vitest 覆盖牌型、12 名英雄技能、城邦与状态触发、过期命令、seed 重放、存档恢复、阵营结算，以及 1,000 局完整 AI 对战中的合法行动、54 张牌唯一归属和每次行动后的存档有效性；另外验证盖伦额外回合保存、恢复与后续出牌 / 过牌顺序。
- React Testing Library 覆盖选英雄、抢地主、提示、焦点与快捷键、技能 / 城邦 / 结算依次播报、私密事件过滤、暂停与静音。
- Playwright 验证 `1440×900`、`1280×720`、`812×375`、`667×375`、`390×844`，覆盖刷新续局、预选保留、练习、完整对局和结算重开，并用 axe 扫描关键流程的 WCAG A/AA 规则。
- AI 对照脚本在同一套规则与种子下比较标准策略和旧版参考策略，分别报告地主 / 农民胜率及本机决策耗时。结果与验收范围见 [游戏体验优化验收报告](docs/reports/game-quality-implementation.md)。

## 目录

- `src/domain/`：可序列化的牌局状态、唯一 reducer、规则、AI、英雄机制和设置兼容层。
- `src/app/`：Context、控制层和应用入口；负责 AI 计时、音频、快捷键和 UI 状态。
- `src/components/`：英雄选择、HUD、座位、牌堆、手牌、操作栏、播报与原生 dialog。
- `src/styles/`：全局基础样式与设计令牌；组件样式使用 CSS Modules。
- `src/assets/runtime/`：Vite 唯一可引用的 WebP/MP3 运行时资产。
- `assets/`：原始素材与来源说明，不会自动进入生产包。
- `tests/e2e/`：Playwright 与 axe 浏览器验收。

## 构建与发布

```powershell
npm.cmd run build
npm.cmd run preview
```

发布 `dist/` 即可。Vite 生成带哈希的资源文件，`base` 使用相对路径，可部署在静态站点的子目录；构建脚本先检查应用与构建配置的 TypeScript，再运行 Vite。发布前使用 `npm.cmd run build:release` 同时检查资源预算。

运行时不会复制原始 PNG 图集、本地服务文件、测试或未引用语音。重新生成优化资产可执行：

```powershell
npm.cmd run assets:optimize
```

项目使用英雄联盟 / 符文之地风格的角色与视觉资产，仅按非商业原型处理；公开发布前仍需单独审查素材授权。
